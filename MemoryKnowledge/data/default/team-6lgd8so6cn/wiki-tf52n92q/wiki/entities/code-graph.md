# Code Graph

## Definition

Code Graph is a knowledge source type within the [[Knowledge Base]]. It represents a structured representation of code relationships that agents can query to enhance their responses with code-level, domain-specific information.

## Key Attributes

- Structured representation of code relationships.
- Queryable by agents.
- Complements [[Wiki]] as a knowledge source type.

## Relationships

- Contained within the [[Knowledge Base]].
- Complementary to [[Wiki]] as a knowledge source.
- Accessed via [[MemoryKnowledge]], which implements knowledge base ingestion and search.
