# Wiki

## Definition

Wiki is a knowledge source type within the [[Knowledge Base]]. It represents structured, human-curated documentation that agents can search to enhance their responses with domain-specific information.

## Key Attributes

- Structured and human-curated.
- Searchable by agents.
- Complements [[Code Graph]] as a knowledge source type.

## Relationships

- Contained within the [[Knowledge Base]].
- Complementary to [[Code Graph]] as a knowledge source.
- Accessed via [[MemoryKnowledge]], which implements knowledge base ingestion and search.
