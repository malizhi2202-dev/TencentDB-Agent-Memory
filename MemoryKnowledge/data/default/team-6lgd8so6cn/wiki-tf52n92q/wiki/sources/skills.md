# Skills

## Source Summary

This document defines **Skills** as executable knowledge packages that agents load and use, injected into every LLM request via [[MemoryProxy]]. It explains their significance — modular, executable knowledge that enhances agent capability and is automatically available during LLM interactions — and identifies related entities ([[MemoryProxy]], [[knowledge-base]]) and common topics (data flow, system architecture).

The document is a concept definition page sourced from README.md.

## Key Points

- Skills are executable knowledge packages loaded and used by agents.
- Skills are injected into every LLM request via [[MemoryProxy]].
- Skills enhance agent capability through modular, automatically available knowledge.
- Skills may be derived from or supplemented by [[knowledge-base]] content.
