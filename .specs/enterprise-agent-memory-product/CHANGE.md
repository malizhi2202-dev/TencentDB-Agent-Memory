## 目标

为企业团队提供一个可审计的 Agent Memory 管理工作台：让用户在跨 Harness 工作中知道记忆来自哪里、属于谁、谁能使用、如何进入知识化发布，以及撤回、清理、通知和高风险执行是否真正完成。
