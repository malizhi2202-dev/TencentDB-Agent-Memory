8 · 术语表

本章回答：文档里那些加粗术语到底指什么。定义以本表为准；与散落各章的简述不一致时，以本表为权威口径。

术语定义首次出现
Principal经认证的操作主体，可能是 User，也可能是服务主体。未识别真人时为 actor_unknown。§2.1
Credential认证凭据：包含 scope、指纹、到期与撤销状态。系统只保存哈希 / 指纹，明文仅在创建时展示一次。§2.1
Team组织与共享协作层，管理成员、Team scope 资源与默认规则。§2.2
Project具体协作现场，组织 Task、关联 Agent 与 Project scope 资源。§2.2
Agent可版本化的执行配置：职责、模型、工具与资源装配。关联范围只授予明确的 view / use 能力。§2.2
Harness外部执行环境（Codex / Claude Code / DSH 等）。平台通过 Connector 与其对接，不接管其执行循环。§1.1
Work Thread一次跨 Harness 可交接的工作现场，单一规范归属，默认连续、边界变化才拆分。§2.2
Continuation Package交接产物：规范状态 + 接手者投影。必须经接手者明确确认后才生效。§2.2
TaskProject 内带验收标准的工作目标。不是执行记录。§2.2
Run一次执行尝试及其不可改写证据。Run succeeded ≠ Task accepted。§2.2
ContextBinding本次工作的主 Project、只读参考 Project 与唯一写入目标空间。§2.2
CodeScenario代码场景：由代码版本、症状、失败、根因、修复与验证组成，可恢复、可复用。§2.2
Evidence对话、Trace、日志、指标、工具结果、代码 diff、测试、人工判断或 Provider 回执。证据与结论分别版本化。§2.2
MemorySpace记忆的归属、可见性与写策略边界。owner 只有 user / team / project / agent 四类，不提供 public Memory。§2.3
MemoryItem记忆候选或已确认记忆：层级（L0–L3）、来源、置信度、敏感性、Owner、Purpose 与生命周期。§2.3
KnowledgeAsset可复用知识资产：Wiki、Skill、RCA、Template、Code Context，各有独立来源与版本语义。§2.3
ChangeSet对记忆 / 知识 / 策略的变更候选，经 Review 后 Publish。内容变更的唯一审核对象。§2.3
ProcedureTemplate可复用步骤 / 流程模板。引用锁定版本，升级或派生都是显式 ChangeSet，不自动同步。§2.3
SnapshotTask 的 planning snapshot 或 Run 的 actual snapshot。不可被最新配置回填或篡改。§2.3
Purpose本次读取、复用、导出或执行的用途。它参与权限判定，不是备注字段。§2.4
VisibilityContext一次判定的完整上下文：主体、委托、源 / 目标空间、Purpose、ACL、敏感性、revision、环境与策略版本。§2.4
ContextManifest本次 Run 实际使用的记忆、知识与证据清单。§2.4
CopyInventory源资产的版本化副本清单：在线索引、缓存、Embedding、Manifest、导出、备份、Provider、终端。§2.4
ExportAsset绑定源 revision、范围、接收者、用途、有效期与证据的导出对象。§2.4
ToolPolicy工具能力的硬边界。RunGate 只能在它之内收紧，不能放宽。§2.4
RunGate高风险工具副作用的动态执行准入，执行过程中持续重检。§2.4
ActionProposal默认不可执行的动作建议；通过当前 RunGate 后才能进入受约束 Run。§2.4
Triage
分诊		对导入候选做归属判定与风险分级的唯一人工处理入口：确认归属、转人工、隔离。§1.2
Review / Publish内容审核与发布两个独立步骤。approved ≠ published。§2.5
Projection
投影		按接收者授权裁剪字段后的视图。必须先授权投影，再渲染输出。§2.4
Delivery Intent一次投递的意图记录（接收者、渠道、版本、有效期），与渠道实际 Attempt 分开记录。§5.16
Provider
再处理者		代平台处理数据的外部服务 / 供应商，属于独立副本面，需要范围绑定证明与审计权。§5.15
accessible / mounted / effective三层资源状态：主体可用候选 / Agent 默认装配 / 某次 Run 实际解析出的不可变集合。三者不可互换。§5.6
fail-closed无法证明、权限不明、状态未知时，优先收窄、隔离、阻断与升级，而不是乐观放行。§2.6
Legal Hold
法律保全		因法律原因暂停处置的状态。保留不等于服务可见：retained ≠ service-visible。§5.15
Break-Glass紧急访问通道：留痕、限时、事后复核，有明确边界，不作为常规放行路径。§7.3
SoD
职责分离		提出者与批准者分离、审批绑定计划版本、清理与验证分离等硬约束。§7.3
