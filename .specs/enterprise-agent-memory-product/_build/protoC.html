同一个「空」不是同一个原因

空列表至少区分：确实没有对象（empty）、有对象但被筛选或权限排除（filtered-empty）、只取到部分范围（partial）、无权访问（denied）、服务失败（error）、离线快照（offline）、证据过期（stale）。未观察不等于不存在，看不到也不等于没有；unknown 不能当 0，无权结果不得泄露对象名称、类型、数量或存在性。

loading 加载中

何时出现
首次进入或切换 scope，权限过滤与索引查询尚未返回
页面显示
骨架占位 + 「正在按当前权限过滤」；不显示任何计数，避免用 0 暗示结果
下一步
等待返回；超过 8 秒转 error，保留重试入口与请求 ID

empty 确实为空

何时出现
当前 scope 内确实没有对象，且权限过滤已完成
页面显示
「当前 scope 内没有对象」+ 明确范围（p-db · project/p-db）+ 过滤已完成说明
下一步
创建、导入或切换 scope；不暗示「可能有但你看不到」

filtered-empty 筛选后为空

何时出现
存在对象，但被当前筛选条件或权限条件排除
页面显示
「0 条匹配」+ 已排除原因类别；数量只按策略返回分桶 / 近似值，不返回精确数
下一步
调整筛选条件，或按入口申请授权；保留筛选条件回显

partial 部分完成

何时出现
影响闭包未遍历完、分区未返回、Provider 未回执或扫描被限流
页面显示
覆盖率分母 + 盲区 + 快照时间点 + 显式 partial 标记；不用单一百分比代表全量
下一步
等待分区完成或发起对账；截断、超时与无权范围不得标作 complete

denied 无权访问

何时出现
当前主体对该对象或该动作没有授权（含策略硬拒绝）
页面显示
统一拒绝文案：「无权访问此对象（或该对象不存在）」；不返回对象名称、类型、精确数量、路径或存在性，与「不存在」保持一致响应
下一步
申请授权或切换到有权限的 scope；不提供「猜一猜」式的重试与计数回显

error 失败

何时出现
策略、血缘、索引或审计服务调用失败，或返回结果不完整
页面显示
错误类别 + 请求 ID + 已重试次数；不显示后端堆栈、SQL、内部路径或他人对象信息
下一步
重试或联系责任人；策略 / 审计不可用时高风险动作 fail-closed 阻断，不放行

offline 离线

何时出现
Connector / Harness 离线，或网络与外部系统不可达
页面显示
离线标识 + 数据新鲜度 + 「当前显示 2026-09-21 14:32 的快照」；离线期间的写动作明确标注不可提交
下一步
恢复连接后重新校验权限与撤回状态；离线不改用缓存结果充当实时结果

stale 证据过期

何时出现
快照超过有效期、Provider 状态未回填、revision 或策略版本漂移
页面显示
stale 徽标 + 最后确认时间 + 需要重算的范围 + 责任角色
下一步
触发重算或对账；stale 不得当作 current，旧证明与旧幂等键不得覆盖新 revision 状态

success 成功

何时出现
请求范围在某个版本快照下完成计算或处置
页面显示
成功 + 声明范围 + 证据时间 + 证据引用（如 ev-7781）+ 明确不适用范围
下一步
查看证据或关闭任务；success 只对声明范围成立，不等于全局已验证，也不授予新的执行或外发权限
