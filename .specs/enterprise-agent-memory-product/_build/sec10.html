10.5 维护约定

  • 这是活文档。后续任何 CHANGE 只要触及产品行为或界面，必须同步更新本文档对应章节；对齐检查会核对本文档与代码 / 需求的一致性。
  • tokens 单一来源。本文档 :root 的 CSS 变量与 UI-DESIGN.md 同源；任何一侧变更都要同步另一侧。
  • §5 与 §6 联动。新增或调整模块时，使用指南与界面原型必须一起改；§5.0 与 §7 的角色可见性必须同时更新。
  • 不冻结未决实现。涉及 Schema、阈值、算法、SLA、责任矩阵、合同与法域模板的内容，一律保留「待确认 / 暂缓」标记，直到有真实输入。
  • 禁止宣称为最终结论。本文档是产品设计文档，不是法律、合规或工程实现结论。
