0 · 这份文档怎么读

这一章告诉你：本文档是什么、不是什么，以及不同角色应该从哪一章开始读。全文只有一个目标——让「记忆从哪里来、属于谁、谁能用、怎么发布、怎么撤回」这几件事在同一份文件里说清楚。

0.1 文档定位

本文档是 Enterprise Agent Memory Platform 的产品设计文档与全界面原型合一产物：一份自包含的 HTML，浏览器双击即可阅读与演示，不依赖网络、构建或部署。它同时承担两个职责：给人和给 AI 都能读的产品全景说明，以及与真实系统同布局的界面原型。

边界：这是设计文档与只读原型，不是可运行系统

第 6 章的所有界面均为静态复刻，数据全部是虚构的演示数据（页面内以「演示数据」标识）。本 change 不实现真实 API、数据库、鉴权、Provider 删除、终端擦除、消息发送或生产 Run。任何页面上的「执行 / 删除 / 发送 / 迁移」都不产生真实副作用。

0.3 关于「待确认」与「暂缓」

本文档的一部分内容是已确认的产品原则，另一部分是尚未冻结的实现细节。凡涉及具体 Schema、阈值、算法、性能与 SLA、组织责任矩阵、供应商合同和法域模板，本文档一律标注为 待确认 或 暂缓，不把阶段性方案写成最终结论。

全文状态口径统一：requested ≠ executed ≠ verified；retained ≠ service-visible；unknown ≠ zero；approved ≠ published；Run succeeded ≠ Task accepted。
