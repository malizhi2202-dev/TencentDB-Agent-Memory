写策略与 ACL 是两件事

写策略决定「能否写入、写成什么状态」，ACL 与可见范围决定「谁能读、读到哪些字段」；两者都不等于执行权。有效范围取调用凭据 scope ∩ 主体身份 ∩ 来源 ACL ∩ 目标空间策略 ∩ Purpose ∩ 敏感性 ∩ 发布状态，且 target_scope ⊆ effective_scope。
