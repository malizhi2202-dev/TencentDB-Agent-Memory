# V3 原型验证记录

日期：2026-09-11。对象：本目录 `product-design-v3.html`。**这些结果只证明离线原型的可操作性，不代表生产后端或真实鉴权通过验收。**

## 实测环境与范围

- Playwright 1.48.2 / Chromium **130.0.6723.31**，通过 `file://` 直接打开 HTML。
- **31 个页面路由、90 个页面/Tab 组合、31 个内嵌文档视图**逐一渲染；新增独立登录页，并将 Code 来源与分析子页合并到同一工作台。
- 所有页面有有效页头；带 Tab 的页面有唯一活动子导航；未出现页面渲染失败。
- 5 张领域/架构/时序图为离线 SVG；内嵌文档中的本地文件链接均能解析。额外回归覆盖原任务筛选分页、旧检索试调、生产审批、归档候选和未知角色拒绝；旧资产深链仅保留兼容，不再进入一级导航。
- 核心 UI 采用五组导航、独立登录页、可点击团队资料、四维下拉组合筛选、合并后的 Code 工作台、自动归属/人工待办、图谱证据面板、三方审查和并列快照。

## 计数口径与生产边界

- 82 是页面/Tab 路由组合数，不是已实现的后端功能数量。31 是 16 个主设计阅读视图与 15 个需求章节视图。
- 原型的用户、密码、Key、ACL、审批、索引就绪、CAS、版本和审计都在当前页面内存里。整页刷新恢复初始数据；主题可本地保存。
- `verified` 是合成来源对成功事件的声明，仍须复核；未调用真实工具或复现真实执行，不证明泛化成功率。
- 步骤总数、Token、冗长程度、端到端无进展等需要完整消息/步骤证据。本轮原型明确展示缺证边界，不从有限工具事件伪造这些指标；完整目标见 REQUIREMENTS R13。
- 图谱节点、边、相似分、版本和静态源码均为人工样本；不证明真实语言解析覆盖、向量生成、实体抽取或线上拓扑。
- 代码候选不执行 patch、测试、Git commit 或合并；“发布”只记录候选审查状态，不推进真实代码版本。
- 发布依赖就绪与 CAS 是单页模拟，不证明跨服务原子事务。真实授权、签名上下文、持久化、幂等、并发锁、回收保护及灾难恢复仍需研发联调和后端验收。
- 响应式检查并非全部页面、全部字体和所有浏览器的视觉穷举；键盘检查也不替代完整无障碍审计。
