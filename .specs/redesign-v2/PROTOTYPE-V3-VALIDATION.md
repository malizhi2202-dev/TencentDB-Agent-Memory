## 4. 本轮发现并修复

1. 旧版捕获阶段拦截正常控件，且详情深链与历史状态不一致：统一导航解析，排除正常链接/按钮，并补焦点与 Escape。
2. 新版无实体 ID 的子页路由容易把 Tab 当作 ID：为此类路由使用明确的 `_` 占位，并验证深链恢复。
3. 窄屏栅格子项被表格最小内容宽度撑开：修复 grid 子项最小宽度，保留局部表格滚动。
4. 文档中的长英文路由串撑开页面：补断行规则，并为宽表设置可读最小宽度和局部滚动。
5. 文档段落行高影响 SVG foreignObject 标签：图内文本单独维持渲染时行高，避免裁切。
6. Agent 装配快照按当前 Agent 关联 Run 与 revision，不把另一 Agent 的快照作为本轮事实。

## 5. 原型限制与未验证范围

- 所有对象、指标、模型、代码片段、时间与结论均为演示；不代表真实模型效果或真实仓库分析结果。
- 创建、纠错、归档、审批只修改当前浏览器内存，刷新恢复；主题偏好单独保存在本地存储。
- 策略、模板、邀请、API Key 仅预览；无真实认证、授权、数据库事务、幂等、不可篡改审计、审批过期计时或执行恢复。
- 角色切换是体验评审控件，不等于当前 system_admin、TeamRole、ProjectRole 的生产映射。
- 检索为固定候选示意，图谱是有限示例，Analytics 固定汇总与 3 条 Run 样本分别标识；不能据此推导真实全量指标。
- 未执行业务前后端 build、服务单测、迁移、真实 API 集成、权限穿透或性能测试；这些属于下一阶段业务切片。
- 未验证 Safari/Firefox、屏幕阅读器、实际打印机或全量自动无障碍扫描；当前浏览器使用原生 dialog，需要支持该元素的现代浏览器。
- 文档中的完整目标交互（如高级筛选、批量操作、冲突合并、配置真实提交）不等于此次原型全部实现；以本节及表中已验证动作划定范围。
