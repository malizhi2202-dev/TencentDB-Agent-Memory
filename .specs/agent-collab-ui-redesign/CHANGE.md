# CHANGE: MemoryPanel UI 重构 —— 从「知识管理面板」到「Agent 协作平台」

- **Change ID**: agent-collab-ui-redesign
- **创建日期**: 2026-09-02
- **路径建议**: 完整（REQUIREMENT → DESIGN → UI-DESIGN → TASK → DEV → TEST → REVIEW → INTEGRATION）
- **状态**: draft

---

## Why（为什么做）

现有 MemoryPanel 界面是「知识管理」导向——侧边栏 4 组（工作台 / 组织与权限 / 资产管理 / 代码分析），主体是 Wiki、Code_Graph、Skill、Chat_Memory、代码分析这些「知识资产」，团队与项目只是辅助入口。

但产品方向已经转向「**Agent 协作平台**」。前面几轮的三平台比对研究（`.specs/intent-os-mindmemos-adoption.md`，算法 A1–A21 / 关系 R1–R10 / 功能 F1–F25 / 断点①–⑤）+ 用户确认的功能清单（协作项目 9 项、team 4 项、agent 10 字段、记忆空间、算法评估）都无法在现有信息架构里安放：

- 「协作项目」现在只有一个扁平的 `projects` 页，承载不了任务拆解 / 交付物 / 决策 / OKR / 规约 / 工作空间 / 挂载记忆空间；
- 「agent」现在只有基础字段列表，没有可见性 / 执行环境 / MCP / 是否提供 API 等配置面；
- 「记忆空间」散在 Chat_Memory 查看器里，没有独立的管理/挂载入口；
- 记忆能力的「算法评估 / 关系 / 质量治理」没有可操作的界面承载。

**触发原因**：现有 UI 的结构和视觉都不再匹配新需求，需要一套新的信息架构 + 视觉系统来承载「Agent 协作平台」。

## What（做什么）

把 MemoryPanel 前端从「知识管理面板」重构为「Agent 协作平台」：

1. **信息架构重构**：导航从「知识资产为中心」改为「协作项目 / 团队 / Agent / 记忆空间」为中心，知识资产（Wiki/Code/CodeGraph/Skill）降级为可挂载到项目与 agent 的「资产」；
2. **视觉系统重设计**：按选定的调性重建 design tokens + 组件视觉，替换当前散乱的样式；
3. **页面骨架落地**：为协作项目（含任务/交付物/决策/OKR/规约）、agent 配置（可见性/执行环境/MCP/API）、记忆空间管理、以及算法评估/质量面板建立页面与路由骨架。

底层数据模型与算法实现**不在本次**（见「范围排除」）。

## 视觉调性（前端项目必填，由 0-change 步骤 0.6 预选填入）

- **选定**：2️⃣ 极简（Minimal）
- **理由**：技术工具 B2B、高频专注使用，Linear/Vercel 的「单色 + 几何字 + 留白」最能容纳复杂的项目/agent/记忆结构而不显乱。
- **特别说明（用户拍板）**：**保持现有视觉风格**（tea-component + 腾讯蓝品牌色 + 中性灰），**不新建 OKLCH tokens、不大改颜色字体**。本次真正要重设计的是**页面布局 / 信息架构**（导航结构、页面区块、栅格排版）；视觉仅做「收敛」（散落内联样式统一走现有 `--tea-color-*` token），不做「重建」。
- **参考产品**：Linear、Vercel、Stripe
- **明确排除**：玩具（高饱和圆角）、复古未来（霓虹）、奢华（衬线金属）、有机（暖色流动）、粗野（反美学）、编辑式（长文）、极繁（信息过载）——均不适合严肃的工程师运维工具。

## 范围排除（这次不做）

- **不做后端数据模型迁移**：协作项目/决策/OKR/交付物/agent 执行环境等新实体只做 UI/类型层草图，不建库表、不改 `MemoryCore`。
- **不做算法实现**：A1–A21（RRF/检索评估/token-budget/dreaming 改进等）属于内核召回链路，另开 change。
- **不做沉淀链接线**：断点①（Playbook 接服务/HTTP/UI）虽与 UI 相关，但其后端接通先行，另开 change。
- **不做功能完全可用**：本次交付「页面骨架 + 样式」，各页面的真实数据打通按后续 change 逐个接。

## 验收线（粗粒度，不是 AC）

- 新版导航能覆盖「协作项目 / 团队 / Agent / 记忆空间」四大块，且能导航到所有新页面骨架。
- 选定调性的 design tokens 已建立并在全局生效，视觉不再是当前「知识管理」的旧样式。
- 首页不再以「任务看板 + 知识资产」为唯一中心，而是呈现 Agent 协作平台的核心入口。

## 风险与未知

- 界面大改对存量用户有学习成本（需同步引导/公告）。
- 页面骨架与后端数据模型的「先后」需明确：UI 先出骨架，后端 lag，避免出现「点了没数据」的页面（用空态/占位处理）。
- 旧路由需做兼容重定向（现有 `/graph`、`legacyHashToPath` 等兼容逻辑要保留或迁移）。
